# Lystårnet

Et matematikspil til 1. klasse — en rejse gennem matematikkens verden — med en voksendel
(gymnasiematematik i hovedet, forældreoverblik og familieduel).

**Spil:** https://jimmyfabe.github.io/Lystaarnet/

- Lavet til iPad (landskab) og iPhone. Alt læses højt på dansk; tal, prikker og billeder bærer betydningen.
- Virker offline efter første besøg. Ingen reklamer, ingen sporing, ingen konto — fremskridt gemmes kun i browseren.
- Læg spillet på hjemmeskærmen: Safari → Del → Føj til hjemmeskærm.

Repoet indeholder kun de filer, spillet bruger. Udviklingen foregår et andet sted.
